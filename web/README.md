# Coffee Shop POS Frontend

Frontend web app kasir coffee shop berbasis Next.js App Router, TypeScript, Tailwind CSS, dan komponen bergaya shadcn/ui.

## Halaman

- Dashboard
- POS / Cashier
- Menu Management
- Inventory
- Transactions
- Payments
- Reports
- Settings
- Public Receipt

## Menjalankan

```bash
cd web
npm install
npm run dev
```

## Catatan

- Saat ini memakai data dummy/mock.
- Struktur komponen dibuat reusable agar mudah dihubungkan ke backend Express + Prisma pada tahap berikutnya.
